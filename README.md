Library Management System in (c)

A beginner-friendly, menu-driven Library Management System built using C programming.

Features

- Add new books
- Display all books
- Issue books
- Return books
- Store book records in a binary file

Concepts Used

- Structures ("struct") 
- Functions
- Loops and conditional statements
- File handling
- "fread()", "fwrite()", and "fseek()"

How It Works

The program provides a menu that lets users choose an operation. Book details are stored in a binary file so that records can persist between program runs.

What I Learned

Through this project, I practised using structures, organizing code with functions, and managing file records in C.
